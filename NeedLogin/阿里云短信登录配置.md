# 阿里云短信登录配置

登录页现在支持两种方式：后台已启用手机号的短信验证码登录，以及站长配置的用户名和密码登录。

## OSS 共享目录

`SHARED_DIRECTORY` 已与 `NoNeedLogin/.env` 使用同一个 OSS 地址；`OSS_ACCESS_KEY_ID` 和 `OSS_ACCESS_KEY_SECRET` 也沿用该配置。应用通过 OSS SDK 浏览目录并生成有时效的对象链接。更换共享桶时，需同步修改这个 OSS URL 和对应的 OSS 凭据。

## 阿里云控制台

1. 开通号码认证服务的短信认证能力。
2. 选择控制台提供的短信签名和验证码模板，并准备好签名名称及模板 CODE。短信模板需要使用号码认证短信验证码接口支持的验证码参数。
3. 创建仅有号码认证短信发送和验证码核验权限的 RAM 访问密钥，不要把密钥提交到代码仓库。

## 环境变量

在运行 `NeedLogin/app.py` 的进程环境或 `.env` 中设置：

```dotenv
ALIBABA_CLOUD_ACCESS_KEY_ID=你的RAM访问密钥ID
ALIBABA_CLOUD_ACCESS_KEY_SECRET=你的RAM访问密钥Secret
ALIYUN_SMS_SIGN_NAME=控制台短信签名名称
ALIYUN_SMS_TEMPLATE_CODE=控制台验证码模板CODE
# 可选；发送和核验时必须保持同一个方案名称
ALIYUN_SMS_SCHEME_NAME=
```

然后在 `NeedLogin` 目录安装依赖并重启应用：

```powershell
python -m pip install -r requirements.txt
```

没有配置阿里云凭据、签名或模板时，用户名密码登录仍可使用，短信发送和核验会提示暂不可用。

## 管理手机号

使用管理员账号登录后打开“用户管理”，添加手机号后会立即启用短信登录。点击“撤销登录”会阻止后续短信登录并停用该号码已有会话；已停用号码可以再次启用，也可以删除账号及关联会话。
